# 🍔 Reel-bites

A full-stack food reels app where users can scroll short food videos, like, save reels, and visit food partner stores.

## ✨ Features

- 🎥 Scroll through short food videos
- ❤️ Like and unlike food reels
- 🔖 Save reels to your collection
- 🏪 Visit food partner store pages
- 👤 User & Food partner authentication
- 📱 Mobile-first responsive design
- ✨ Smooth animations with Framer Motion

## 🛠️ Tech Stack

**Frontend** — React.js, React Router, Axios, Framer Motion, Tailwind CSS

**Backend** — Node.js, Express.js, MySQL, JWT, bcrypt
